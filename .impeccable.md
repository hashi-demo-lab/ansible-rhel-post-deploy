## Design Context

### Users
This presentation landing page serves a broad audience: conference attendees, customers/prospects, executives/decision-makers, and internal engineers. Users encounter it as an Nginx landing page deployed on RHEL hosts provisioned through the CLM pipeline — it doubles as both a demo artifact and a storytelling vehicle for the Certificate Lifecycle Management solution built with HashiCorp Vault and Red Hat Ansible.

### Brand Personality
**Authoritative. Modern. Trustworthy.**

The interface should evoke confidence and trust (enterprise-grade reliability), urgency and impact (the risk of certificate mismanagement is real), and technical credibility (deep domain mastery). It should feel like a premium product experience — polished and modern without being flashy.

### Aesthetic Direction
- **Visual tone**: Clean, modern enterprise SaaS — inspired by HashiCorp.com's design language
- **Theme**: Light mode with warm/cool section variation (current oklch-based token system)
- **Typography**: Outfit (headings, bold/authoritative) + DM Sans (body, clean/readable) — keep this pairing
- **Color palette**: Warm neutrals with brand accents — Vault gold (#FFD814), Red Hat red (#EE0000), accent purple (oklch 55% 0.15 270)
- **Motion**: Horizontal slide navigation with reveal animations, respects prefers-reduced-motion
- **Anti-references**: Avoid generic corporate template aesthetics, overly playful/startup-y vibes, or cluttered dashboards

### Design Principles
1. **Clarity over cleverness** — Every visual choice should make the story easier to follow, not harder. The audience ranges from engineers to executives; the design must serve both.
2. **Brand authenticity** — Lean into HashiCorp and Red Hat visual identities without mimicking either brand's site wholesale. The gold + red accent system creates a distinct identity for this joint solution.
3. **Progressive disclosure** — The horizontal slide format should reveal information at a narrative pace. Animations support comprehension, not decoration.
4. **Technical credibility through design** — Clean typography, precise spacing, and purposeful color use signal the same engineering rigor as the solution itself.
5. **Accessibility as baseline** — Maintain reduced-motion support, sufficient contrast ratios, and keyboard navigability. Best-effort WCAG AA compliance.
